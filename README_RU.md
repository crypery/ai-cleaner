# AI-Trace Cleaner

> [English version](README.md)

`AI-Trace Cleaner` — это консольная утилита на языке Go, предназначенная для автоматической очистки исходного кода (`.c`, `.cpp`, `.h`, `.py`, `.go`, `.html`, `.css`, `.js`) и файлов документации (`.md`, `.txt`) от характерных артефактов и стилистических «следов», оставляемых языковыми моделями (ИИ) при генерации текста.

Программа помогает привести файлы к естественному «человеческому» виду, предотвращая автоматическое или визуальное обнаружение факта генерации контента.

## ✨ Функциональность

Утилита выполняет рекурсивный обход указанной директории и применяет к целевым файлам комплексную очистку:

1. **Удаление эмодзи:** Полностью вырезает любые Unicode-эмодзи, которые ИИ часто использует для структурирования документации.
2. **Исправление псевдографики:** Заменяет длинные символы рамки/псевдографики (`─`) на стандартные машинные дефисы (`-`).
3. **Стандартизация кавычек:** 
   * Заменяет французские кавычки-ёлочки (`«` и `»`) на символы сравнения (`<` и `>`).
   * Заменяет английские «умные» фигурные кавычки (`“` и `”`) на стандартные прямые кавычки (`"`).
4. **Нормализация пунктуации:** Автоматически удаляет случайные пробелы перед знаками препинания (`.`, `,`, `:`, `;`, `!`, `?`), которые часто проскакивают в генерациях.
5. **Форматирование списков (только для `.md`):** Находит маркеры списков в виде звездочек (`* `) и заменяет их на дефисы (`- `), бережно сохраняя при этом исходный уровень вложенности и отступы.
6. **Очистка стоп-фраз ИИ:** Подавляет более 20 характерных вводных, связующих и резюмирующих конструкций как на русском, так и на английском языках (например: *«Конечно, вот...»*, *«Важно отметить, что...»*, *«In conclusion...»*), заменяя их на технические аналоги или полностью удаляя.
7. **Схлопывание пустых строк:** Находит избыточные разрывы страниц (3 и более переноса строки подряд) и аккуратно уменьшает их до одной пустой строки.
8. **Стандартизация окончаний строк:** Принудительно переводит все файлы на единый Unix-стандарт переноса строк LF (`\n`), удаляя Windows-символы CR (`\r`).
9. **Маскировка метаданных времени (Anti-Forensics):** Чтобы избежать подозрений из-за одновременного изменения всех файлов, утилита берет оригинальное время модификации каждого файла и индивидуально сдвигает его назад на случайное количество минут (в диапазоне от 0 до 359 минут).

## 🚀 Установка

Для компиляции утилиты вам понадобится установленный [Go](https://go.dev) версии 1.16 или выше.

1. Склонируйте репозиторий или сохраните код программы в файл `ai-cleaner.go`.
2. Скомпилируйте исполняемый файл:
   ```bash
   go build -o ai-cleaner ai-cleaner.go
   ```

## 💻 Использование

Запуск утилиты осуществляется через терминал. В качестве обязательного аргумента необходимо передать путь к целевой директории через флаг `-dir`.

### Прямой запуск через Go:
```bash
go run ai-cleaner.go -dir="/path/to/your/project"
```

### Запуск скомпилированного бинарника:
* **Linux / macOS:**
  ```bash
  ./ai-cleaner -dir="/path/to/your/project"
  ```
* **Windows:**
  ```cmd
  ai-cleaner.exe -dir="C:\(\path\to\your\project\)"
  ```

## ⚠️ Важные примечания по безопасности кода

* **Безопасность указателей в C/C++:** Алгоритм замены маркеров списков (со звездочек `*` на дефисы `-`) изолирован и применяется **строго внутри файлов с расширением `.md`**. Это гарантирует, что операции разыменования указателей, объявление типов вроде `int*` и многострочные комментарии `/* ... */` в коде на C/C++ не будут повреждены.
* **Умная перезапись:** Программа считывает файл и перезаписывает его на диск только в том случае, если в нем были обнаружены и изменены нежелательные паттерны. Если файл изначально «чист», его системные метаданные (включая дату изменения) останутся нетронутыми.

## 🤝 Советы по комплексной маскировке

Автоматическая очистка текста — это лишь часть задачи. Для достижения максимального результата рекомендуется:
* Перед запуском утилиты отформатировать код на C/C++ с помощью `clang-format`, чтобы сгладить «идеальный» стиль отступов ИИ.
* Не коммитить все изменения в Git одним огромным пушем. Разбейте правки на 2-3 логических коммита.
